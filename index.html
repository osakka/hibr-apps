hibr apps

The application catalogue the apps command installs from — applications for the hibr desktop, each one a script you can read before you run it.

Use it

apps list
apps info snake
apps install snake

Installing places the app where the desktop already looks ($XDG_DATA_HOME/hibr/apps), so it is on the Applications menu the next time the desktop starts. apps remove takes it away again.

What you are trusting

An app is a hibr script and runs with everything your own shell can do: there is no sandbox, and there are no signatures here. TLS says which server the index came from, and the sha256 in the index says the bundle was not changed on the way — neither says who wrote it. The bundles are plain files in this repository: read one before you install it.

Every version ever published stays in bundles/, and the index offers the newest of each. The whole catalogue is one folder, so a mirror is a copy rather than a rewrite: apps index URL points at any copy of it.
