hibr apps

The catalogue the apps command installs from — everything the hibr desktop scans for, each one a script you can read before you run it.

Use it

catalogue list
catalogue info snake
catalogue install snake

Installing places a file where the desktop already looks, so it is there the next time the desktop starts: an application under $XDG_DATA_HOME/hibr/apps, a Control Panel pane under control-panel/, a theme under themes/, and so on for all eight kinds. Something that brings its own pane, Control Strip module or picture brings it as a plain file of its own, named in this index with its own sha256, and each part is placed in the root it names — every one fetched and verified before any is written, so an entry with one bad part installs nothing at all. catalogue remove takes it away again, keeping any part another installed app brings too.

What you are trusting

Five of the nine kinds are hibr scripts and run with everything your own shell can do: there is no sandbox. Three — themes, colour schemes and languages — are data, read rather than run, which is deliberate: they are the things people hand each other, and a theme that was a script would run as whoever applied it. The ninth is mods, a hibr module: native code, with no sandbox at all, which is why apps refuses to install one from a catalogue it cannot verify.

TLS says which server the index came from; the sha256 in the index says the bundle was not changed on the way; and the detached signature beside the index (index.json.asc) says who published it — the same key that signs the apt repository, A1E3CA78 8A8FB020 52DA22B4 13035BE1 B1674431. Because the index carries every bundle's hash, that one signature covers every bundle. What it does not say is that an app is any good.

The bundles are plain files in this repository: read one before you install it — that is the point of an app being a script. Every version ever published stays in bundles/, and the index offers the newest of each. The whole catalogue is one folder, so a mirror is a copy rather than a rewrite: apps index URL points at any copy of it.
